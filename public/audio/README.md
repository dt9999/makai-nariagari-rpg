# Audio provenance

The `.ogg` sound effects in this directory are renamed selections from Kenney's
**RPG Audio** pack, version 1.0 (2014).

- Source: https://kenney.nl/assets/rpg-audio
- License: Creative Commons CC0 1.0
- Creator: Kenney (www.kenney.nl)

The adaptive background ambience is generated at runtime by `app/audio.ts` and
does not use a third-party music recording.
